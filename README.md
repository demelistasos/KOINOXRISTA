# Κοινόχρηστα

Εφαρμογή για τον υπολογισμό κοινοχρήστων πολυκατοικίας, για **Windows και macOS** (Electron).
Είναι η νέα έκδοση της παλιάς εφαρμογής SwiftUI/Xcode, με καινούργιο σχεδιασμό και διορθώσεις.

## Τι κάνει

- Πολλές πολυκατοικίες, η καθεμία με τα διαμερίσματά της (κωδικός, ένοικος, όροφος, τ.μ.).
- Κάθε μήνας αποθηκεύεται ξεχωριστά: έξοδα, πετρέλαιο, ενδείξεις θερμιδομετρητών, υπόλοιπα και πληρωμές.
- **Ιστορικό**: οι κλειστοί μήνες μένουν διαθέσιμοι για ανάγνωση και για ξανά εξαγωγή PDF.
- **Συγκεντρωτικός πίνακας** (A4 οριζόντιο) και **ειδοποιητήρια** (ένα A4 ανά διαμέρισμα) σε PDF.
- Κλείσιμο μήνα: οι νέες ενδείξεις γίνονται παλιές, το απόθεμα τέλους γίνεται αρχή, τα υπόλοιπα μεταφέρονται και τα «καρφιτσωμένα» έξοδα επαναλαμβάνονται.
- Αυτόματη αποθήκευση, αντίγραφα ασφαλείας και επαναφορά (JSON), φωτεινό και σκούρο θέμα.

## Πώς υπολογίζονται τα ποσά

| Κατηγορία | Κατανομή |
|---|---|
| Γενικά έξοδα (ΔΕΗ, νερό, καθαρισμός, καυστήρας, πυροσβεστήρες, απολύμανση, διαχείριση, λοιπά) | Χιλιοστά = τ.μ. / σύνολο τ.μ. × 1000 |
| Ανελκυστήρας | Χιλιοστά × συντελεστής ορόφου, αναγμένα στα 1000 |
| Θέρμανση — πάγιο (π.χ. 20%) | Χιλιοστά |
| Θέρμανση — χρήση (π.χ. 80%) | Χιλιοστά × μονάδες θερμιδομετρητή |

- Κόστος πετρελαίου = λίτρα που καταναλώθηκαν × **μέση σταθμισμένη τιμή** (απόθεμα αρχής με την τιμή που μεταφέρθηκε από τον προηγούμενο μήνα, και κάθε αγορά με τη δική της τιμή).
- Όλα τα μερίδια στρογγυλοποιούνται σε λεπτά με τη μέθοδο του μεγαλύτερου υπολοίπου, ώστε να αθροίζουν **ακριβώς** στο σύνολο κάθε εξόδου.
- Νέο υπόλοιπο = προηγούμενο υπόλοιπο + έξοδα μήνα − πληρωμή.

## Διορθώσεις σε σχέση με την έκδοση Xcode

1. Τα στοιχεία του μήνα (έξοδα, δεξαμενή, τιμή, ποσοστό παγίου) αποθηκεύονται και είναι ξεχωριστά για κάθε πολυκατοικία.
2. Υπάρχει ιστορικό μηνών με δυνατότητα επανεξαγωγής PDF· οι κλειστοί μήνες κρατούν τα στοιχεία των διαμερισμάτων όπως ήταν.
3. Η οφειλή ενημερώνεται αυτόματα στο κλείσιμο (υπόλοιπο − πληρωμή).
4. Οι αγορές πετρελαίου (πολλές ανά μήνα, με ημερομηνία) μπαίνουν στο κόστος με τη δική τους τιμή.
5. Οι συντελεστές ασανσέρ συνεχίζουν πάνω από τον 6ο όροφο και ρυθμίζονται ανά πολυκατοικία.
6. Τα ειδοποιητήρια βγαίνουν ανά διαμέρισμα, όχι ανά όνομα, οπότε δεν μπερδεύονται συνονόματοι.
7. Τα PDF φτιάχνονται από HTML με σωστή αλλαγή σελίδας, οπότε τίποτα δεν κόβεται.
8. Προειδοποιήσεις για ελλιπή στοιχεία: λείπει ένδειξη, νέα ένδειξη μικρότερη από την παλιά, απόθεμα τέλους μεγαλύτερο από το διαθέσιμο. Αν δεν υπάρχει καθόλου χρήση, το μεταβλητό μέρος της θέρμανσης μοιράζεται με τα χιλιοστά αντί να χάνεται.
9. Δυνατότητα εξαίρεσης διαμερίσματος από θέρμανση ή ασανσέρ.

## Ανάπτυξη

Χρειάζεται [Node.js](https://nodejs.org) 20 ή νεότερο.

```bash
npm install
npm start          # τρέχει την εφαρμογή
npm test           # tests υπολογισμών
npm run dist:win   # installer για Windows (σε Windows)
npm run dist:mac   # .dmg για macOS (σε Mac)
```

Τα έτοιμα αρχεία εγκατάστασης φτιάχνονται και αυτόματα στο GitHub. Αν ανεβάσεις ένα tag (π.χ. `v2.0.0`) ή τρέξεις το workflow **Build** από την καρτέλα Actions, βγαίνουν ένα `.exe` για Windows και ένα `.dmg` για macOS.

> Σε macOS η εφαρμογή δεν είναι υπογεγραμμένη. Την πρώτη φορά άνοιξέ τη με δεξί κλικ → Άνοιγμα.

## Πού αποθηκεύονται τα δεδομένα

- Windows: `%APPDATA%\Κοινόχρηστα\koinoxrista.json`
- macOS: `~/Library/Application Support/Κοινόχρηστα/koinoxrista.json`

Δίπλα κρατιέται και η προηγούμενη εκδοχή (`koinoxrista.previous.json`). Ο φάκελος ανοίγει από το μενού **Αρχείο → Άνοιγμα φακέλου δεδομένων**.

## Δομή

```

src/reports.js   HTML για πίνακα και ειδοποιητήρια
src/app.js       διεπαφή
src/styles.css   εμφάνιση
test/            tests υπολογισμών
```
